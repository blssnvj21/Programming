🧑‍🏫 Professor's disclaimer
BananaScript is a deliberately small teaching language, not Python or JavaScript. Its interpreter supports a defined subset of programming constructs. The concepts you learn here transfer to mainstream languages, even though their syntax differs.

🗺️ The complete programming map
ZERO → ADVANCED
This is the long-term syllabus—not a claim that one tiny language contains every feature of every language. Work through the foundations, then study the advanced topics in a real language such as JavaScript, Python, C, C++, Java, or C#.


STAGE 00
Computer & problem-solving basics
Hardware, CPU, memory, storage, operating systems, files and paths, terminal basics, binary, algorithms, pseudocode, flowcharts, decomposition, abstraction, debugging mindset.


STAGE 01
Programming foundations
Source code, compilation vs interpretation, syntax vs semantics, tokens, expressions, statements, literals, identifiers, keywords, comments, whitespace, errors, input/output.


STAGE 02
Types, names & operators
Variables, constants, scope, lifetime, primitive and compound types, strings, numbers, booleans, null-like values, type conversion, inference, mutability, arithmetic, comparison, logical, assignment, bitwise and precedence.


STAGE 03
Control flow
Sequence, if/else, nested conditions, switch/match, loops, while, for, foreach, break, continue, return, early exits, nesting, loop invariants, tracing and termination.


STAGE 04
Data structures
Arrays, lists, tuples, strings, maps/dictionaries, sets, records, objects, stacks, queues, linked lists, trees, heaps, hash tables, graphs, iterators, mutability and copying.


STAGE 05
Functions & modularity
Parameters, arguments, return values, procedures, scope, closures, recursion, overloading, default/named arguments, variadic functions, higher-order functions, lambdas, modules, packages, imports and APIs.


STAGE 06
Errors, testing & quality
Exceptions, error values, assertions, unit/integration/end-to-end tests, test doubles, test-driven development, logging, debugging tools, formatting, linting, documentation and code review.


STAGE 07
Object-oriented programming
Classes, instances, fields, methods, constructors, encapsulation, abstraction, inheritance, composition, polymorphism, interfaces, traits, access modifiers, static members and design principles.


STAGE 08
Functional & declarative ideas
Pure functions, immutability, side effects, map/filter/reduce, composition, pattern matching, algebraic data types, declarative programming and functional error handling.


STAGE 09
Algorithms & complexity
Big-O, time/space complexity, searching, sorting, hashing, recursion, divide-and-conquer, greedy methods, dynamic programming, backtracking, graph traversal and proof of correctness.


STAGE 10
Memory & runtime
Stack and heap, references and pointers, value vs reference semantics, allocation, garbage collection, ownership, borrowing, lifetimes, undefined behavior, runtime, virtual machines and profiling.


STAGE 11
Files, data & networking
File I/O, serialization, JSON, CSV, environment variables, processes, sockets, HTTP, DNS, clients and servers, APIs, databases, SQL, transactions and data validation.


STAGE 12
Concurrency & asynchronous code
Processes, threads, tasks, event loops, callbacks, promises/futures, async/await, race conditions, locks, deadlocks, message passing, parallelism and cancellation.


STAGE 13

Declarations, operators, blocks, functions, classes, generics/templates, modules, exceptions, annotations/attributes, macros, pattern matching, iterators, async syntax and standard-library conventions.

🍌 The BananaScript Engineering Roadmap
SYNTAX THAT RUNS
Mission: learn programming by writing BananaScript—not by copying syntax from C, Python, or JavaScript. Every runnable example in this course uses the syntax accepted by the current BananaScript interpreter. Topics beyond the interpreter are labelled as concepts to learn, not pretend features.
What the language currently runs
Declarations with hoard, output with yeet(...), assignments, arithmetic, comparisons, booleans, panic_if/cope_else, loop_de_loop, while, recipe, send_back, arrays, indexing, and documented built-ins. The interpreter is hand-written and interpreted; it is not a native-code compiler.


UNIT 01
How a program runs
Instructions execute in order. Learn to read a BananaScript program from top to bottom, predict each output, and distinguish source code from the interpreter that runs it.
yeet("First");
yeet("Second");


UNIT 02
Values and types
Numbers, strings, booleans, arrays, and the null literal. Learn literals, quoted text, type inspection with type, and conversions with num and str.
hoard fruit = "banana";
hoard count = 3;
yeet(type(fruit));
yeet(count);


UNIT 03
Names and changing values
Declare a name with hoard; update an existing name with assignment. Understand scope and why a name must exist before it can be updated.
hoard count = 4;
count = count + 1;
yeet(count);


UNIT 04
Expressions and operators
Arithmetic, remainder, comparisons, logical AND/OR/NOT, parentheses, precedence, and string joining with +.
yeet(2 + 3 * 4);
yeet(7 >= 5);
yeet(!false);


UNIT 05
Decisions
Use panic_if for a condition and cope_else for the alternative. Conditions choose which block runs.
hoard stock = 2;
panic_if (stock > 0) {
  yeet("In stock");
} cope_else {
  yeet("Sold out");
}


UNIT 06
Repetition
loop_de_loop repeats a fixed number of times. while repeats while its condition remains true. Learn counters, tracing, and safe termination.
loop_de_loop 3 {
  yeet("Again");
}


UNIT 07
Functions: reusable recipes
Declare a function with recipe, receive parameters, call it by name, and return a result with send_back.
recipe double(n) {
  send_back n * 2;
}
yeet(double(21));


UNIT 08
Arrays and indexes
Store ordered values in arrays. Indexes start at zero. Read or update an existing position, and use len, push, and pop.
hoard fruits = ["banana", "mango"];
push(fruits, "pear");
yeet(fruits[0]);
yeet(len(fruits));


UNIT 09
Built-in helpers
Use the documented helpers abs, floor, ceil, round, sqrt, type, num, and str. Follow each helper's input rules.
yeet(sqrt(81));
yeet(round(4.5));
yeet(str(42) + " bananas");


UNIT 10
Errors and debugging
Read the message, locate the name or symbol involved, check quotes and braces, reduce the failing example, and change one thing at a time.
hoard fruit = "banana;
yeet(fruit);


UNIT 11
Scope and function calls
Learn local parameters, local declarations, variable lookup, return behavior, recursion, and the interpreter's call-depth limit. A recipe that reaches its end returns null.


UNIT 12
Collections and mutation
Arrays are mutable and passed by reference. Explore how push, pop, and indexed assignment change an existing array.


UNIT 13
Algorithms with current features
Build counters, totals, searches, simple inventory tools, and small decision-based programs using only supported variables, loops, conditions, arrays, and recipes.


UNIT 14
How the interpreter works
Study the actual pipeline: tokenizer → parser → abstract syntax tree → evaluator. Understand syntax errors, runtime errors, and why this implementation does not compile to machine code.


UNIT 15
Limits and future language features
Classes, objects, imports, file access, user input, exceptions, pointers, static types, modules, and native compilation are not currently implemented. They are future design topics—not valid BananaScript syntax today.


How to study every unit
  1. Predict: write down what the program should output.
  2. Run: use the BananaScript playground.
  3. Trace: follow each variable and branch.
  4. Break: make one small mistake and read the diagnostic.
  5. Build: solve a related problem without copying.
  6. Explain: describe both what happened and why.
Scope: this is a roadmap for learning programming through the current BananaScript subset. It does not claim that unsupported features already exist.
⌨️ Syntax reference: the shapes to recognize
BANANASCRIPT
BananaScript examples below use the language's primary syntax. The aliases are supported too, but learn one spelling at a time.
Optional aliases
stash = declare a variable · yell(...) = print · again N { ... } = repeat N times · when (...) { ... } otherwise { ... } = if/else. These aliases are real and runnable.
Comments
// A note for humans
yeet("Hi");
Values & variables
hoard name = "Mango";
hoard count = 4;
hoard ready = true;
hoard nothing = null;
Expressions
yeet(2 + 3 * 4);
yeet(count >= 2);
yeet("Hi " + name);
Decision
panic_if (count > 0) {
  yeet("In stock");
} cope_else {
  yeet("Sold out");
}
Repetition
loop_de_loop 3 {
  yeet("Again");
}
Assignment
hoard count = 4;
count = count + 1;
yeet(count);
Functions and arrays
recipe double(n) {
  send_back n * 2;
}
hoard fruits = ["banana", "mango"];
push(fruits, "pear");
yeet(double(len(fruits)));
yeet(fruits[1]);
BananaScript also supports while, arrays, indexing, functions, returns, and documented built-ins. See the language reference for exact limits and unsupported features.
